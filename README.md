# CodeAlpha - Task Automation Script ⚙️

An automated Python script built for the **CodeAlpha Internship Program** to streamline repetitive text-processing tasks.

## 📌 Project Overview
This project automates the extraction of email addresses from text files using Regular Expressions (Regex) and saves the unique results into a formatted output file.

## ✨ Features
- **Regex Extraction:** Accurately identifies standard email pattern formats.
- **Deduplication:** Automatically filters out duplicate email entries.
- **Auto Sample Generator:** Creates a test file if no source text file is detected.
- **Structured Export:** Saves extracted contacts directly to an external text document.

## 🛠️ Concepts Used
- Regular Expressions (`re`)
- OS Module File Verification (`os`)
- Context Managers & File I/O (`open`, `read`, `write`)
